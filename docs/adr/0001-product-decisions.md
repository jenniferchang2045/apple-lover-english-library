# ADR 0001：v1 产品决策

日期：2026-09-05

## 已确认

1. 第一版只服务一个闲鱼卖家账号。
2. 交付形态：一书一个固定百度网盘链接 + 提取码。
3. 标价默认 8.80 元（880 分）。
4. 客服默认 Shadow Mode（`AI_ASSISTED`）：AI 只出草稿，人工发送。接受至少 7 天。
5. 退款、争议、投诉、改价、补偿全部转人工，Agent 不得执行。
6. 告警与异常引入人工处理，不自动关闭或自动退款。

## 版权（工程不让步）

产品希望使用互联网上找到的英文 PDF，并依赖闲鱼版权机制事后下架。

这不能作为自动放行条件：

- 平台下架是风控，不是授权证明。
- `UNKNOWN` / 仅网络来源的资料禁止发布、禁止自动交付。
- 系统不下载、不搬运、不默认批准无权利证明的全文。
- 只有 `PUBLIC_DOMAIN` / `LICENSED` / `ORIGINAL` 且 `rights_status=APPROVED` 才能进入发布与履约。

## 账号接入

使用指定的闲鱼卖家账号，但凭证只进加密 Secret，不进 Git、日志或 Prompt。未取得官方合作方 API 前，连接器保持可替换，默认 Fake。
